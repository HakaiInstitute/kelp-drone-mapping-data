This folder contains:

CentralCoast_SeasonalDroneKelpPolygons.gdb.zip, which includes:
* Point vector features of the location of monitoring sites
* Polygon vector features of canopy kelp
* Polygon vector features of the area of interest (AOI) of each monitoring sites

Kelp_clipped_to_DroneAOIs_20250922.csv:
Table of kelp polygon data for each site. Each row represents an individual kelp polygon, and data can be aggregated by time and space

The data dictionaries for these files are found in the root of the repository.
